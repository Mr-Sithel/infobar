### InfoBar

- Information Bar Overlay that shows: 
* (Job|Compass|pos|Zone Timer|Zone|Region|Day|Weather|Vana Time|Moon Phase).
* (EXP/Limit Points|Merit Count|XP /hr|Merits /hr|XP Chain)
* (Assault Zone|Assult Name|Time Remaining)
* (Corsair Roll Tracker|Lucky/UnLucky|Time REmaining)

### Horizon Server
- InfoBar has been ${\textsf{\color{green}{Approved}}}$ for horizon on 09-04-2026.

### Overview
All Commands below and more can be done from the settings window.

InfoBar Commands:
`/ibar` or `/infobar`
* /ibar c|config|settings    (shows settings window)
* /ibar m|mode               (splits the bar into 2 smaller overlays)
* /ibar w|weekdays           (shows elemental day order)
* /ibar e|exp                (shows exp bar)
* /ibar a|s|assault|salvage (shows an assault/salvage bar.')
* /ibar rt|rolltracker      (shows a COR roll tracker bar.')
* /ibar r|reset             (resets overlay to default location)
* /ibar save                (saves settings)

### Installation

* Download and unzip the correct version of InfoBar at https://github.com/Mr-Sithel/InfoBar/releases/
* Copy the `InfoBar` folder from inside of the `InfoBar-(X.X.X)` folder into your Ashita addons directory
* Addon directory is : `HorizonXI\Game\addons`
* This was created for Horizon `Ashita (Interface v4.30)`
* You can load the addon by typing `/load addon InfoBar`.  It is recommended you add this line to the appropriate place in `scripts/default.txt` to auto load.
